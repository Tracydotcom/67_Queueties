Quick Sort Algorithm

A Quick Sort Algorithm utilizes a pivot and partitions to create a "divide and conquer" style of sorting. The pivot is used as a reference point for partitioning the elements.
Take these numbers for example: 7, 18, 2, 1, 29
"2" is the median where other elements are compared to create partitions. in this case, it compares whether the number is lesser, greater, or equal to 2. The logic is then recursively applied to the partitions resulting in a sorted array.
