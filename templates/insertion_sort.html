Insertion Sort Algorithm

Insertion sort arranges data one element at a time, taking it from the unsorted part of the array and moving it to its correct place in the sorted part. It is mostly used when the list is small, mostly sorted, and when low memory usage is a priority. It is much less efficient for larger lists unlike quick sort or merge sort.

How it works:

- The first element of the array is always assumed to be sorted. The rest are considered unsorted.
- The second element will then be compared to the former and will be swapped if needed.
- The next elements will be compared to all elements of the sorted part until the whole array is sorted.

Time Complexity: O(n^2) in the average and worst cases, O(n) in the best case.
Space Complexity: O(1) as it is an in-place sorting algorithm.
