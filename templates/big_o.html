Performance Analysis

An exploration of algorithmic efficiency. This page analyzes how different sorting methods perform as the dataset size increases.

The "Slow" Group O(n²)

Quadratic Time

Bubble Sort Insertion Sort Selection Sort

These algorithms are like biking across the country. They work for small lists but freeze up when data grows.

  • Analogy: The Handshake Problem. If everyone shakes hands with everyone else, the work explodes.
  • Technical: Uses nested loops.
The "Fast" Group O(n log n)

Linearithmic Time

Merge Sort Quick Sort

These algorithms are like flying a jet. They are optimized to handle massive amounts of data efficiently.

  • Analogy: The Dictionary Search. You don't read every page; you split the book in half repeatedly.
  • Technical: Uses "Divide and Conquer."
